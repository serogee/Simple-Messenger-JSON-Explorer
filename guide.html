Open your Messenger JSON exports

Use Simple Messenger JSON Explorer to read your Facebook Messenger exports in a chat view. You can search for a phrase, jump to a date, and browse attachments. You work with files on your device without uploading your conversations.

Download your export

Request your message history in JSON format through Facebook or Messenger. After you download the archive, extract the ZIP file into a folder on your device.

Follow Meta's instructions for your export type:

  • Download your Facebook information
  • Download your Messenger end-to-end encrypted chats

Open a conversation

Open the viewer and use the file picker under Select one or more Messenger JSON files to view. Choose the JSON files for one conversation.

For a split export, select message_1.json, message_2.json, and the other numbered message files from that conversation in one selection. You can read the combined history in date order. Keep files from different conversations in separate selections.

Choose a participant under View from the perspective of. Use Search messages to find an exact phrase, or use the date controls to browse by month, week, or day.

Add photos and other media

Use the second file picker, under Optional: allow access to a separate MEDIA folder, to select the folder with the conversation's attachments.

  • For a standard Facebook export, select the conversation folder that contains the JSON and media files.
  • For an encrypted Messenger export with a separate media folder, select that media folder.

Keep the exported media filenames intact so you can match attachments to the references in your JSON files.

Fix common problems

Missing photos or videos

Extract the archive before you select a media folder. Check that you chose the folder for the same conversation and that it contains the missing files. If your export lacks an attachment, request a new export with media included.

Missing messages

Select the split JSON files for the conversation in one selection. Check the date range you requested from Meta if you still cannot find older messages.

Invalid JSON or an empty conversation

Choose a message JSON file from the extracted archive. If you downloaded HTML, request a JSON export. Open the JSON in a text editor and check for a messages list with entries. You cannot display a conversation from an account settings file.

Privacy and PDF export

You can inspect the source code or download a copy to run on your computer. You read your selected message and media files in your browser without sending them to an upload service.

To save a PDF, choose Export to PDF after you load a conversation. Review the preview before downloading. Treat PDF export as experimental: you may see layout differences or missing media in the result.
